NEON GRID — a mosaic GTA 6-style cover art maker: a 2×2 photo grid above a full-width banner caption, each cell independently croppable, with 3 layouts, 5 neon/sunset colour grades, a palm-silhouette divider, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080. Fully offline — photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
